# DSH local adaptation

This upstream is a complete game-project template, not a set of independent global skills. Its 78 skills reference `.claude/` resources and `project.yaml` in the working project.

For a new game, clone `https://github.com/xgx1/claude-code-game-studios.git`, open that clone as the workspace in DSH dev (http://127.0.0.1:3081), and start with `start` or `prototype`. `AGENTS.md` provides the DSH entry point and `.dsh/skills` exposes the original skills without renaming them.

There is no plugin or bundle to compile. The original Claude Code hooks and permission settings are not auto-loaded by DSH; skill instructions and their scripts remain available, but Claude-specific hook automation is not claimed as adapted.
